# 从零到 Transformer：手写深度学习课程

一门 **细粒度、稳扎稳打** 的深度学习入门课程，全部基于 [marimo](https://marimo.io) 响应式笔记本。

你会从零基础出发，用 NumPy 亲手实现从线性回归到 CNN、LSTM、Transformer 的每一个零件，
最后 3 课平滑过渡到 PyTorch，学会工业界的写法。**每一行关键代码都有中文注释，每一个概念都先讲直觉再讲数学。**

## 适合谁

- 会一点 Python（变量、循环、函数），其他都可以零基础
- 想真正 **理解** 深度学习，而不是只会调包
- 有一台普通电脑即可（**全程 CPU 足够，无需 GPU**）

## 课程特点

- **细粒度**：一课只讲 1~2 个概念，讲透为止，不搞大杂烩
- **手写实现**：梯度下降、反向传播、卷积、LSTM、注意力机制……全部亲手用 NumPy 写一遍
- **折叠讲义**：理论讲解都放在可折叠的区块里，点击展开阅读，读完折叠回来继续写代码
- **沉浸阅读**：纯讲解单元（标题、讲义、答案）的代码默认折叠（`hide_code`），打开笔记本看到的是渲染后的排版而非大段 Python 字符串；**演示与练习单元的代码保持展开**——想看某段讲解的源码，点该单元的"显示代码"即可
- **交互实验**：几乎每课都有滑块等交互部件，拖一拖参数，亲眼看见"发生了什么"
- **动手练习**：每课 2~4 道小题（反向传播等重点课加量），附可展开的参考答案

## 环境安装

需要 Python 3.10 或更高版本，然后：

```bash
# 方式一：pip
pip install -r requirements.txt

# 方式二：uv（更快，推荐）
uv pip install -r requirements.txt
```

> PyTorch 只在课程第 8 部分（最后 3 课）才需要，届时再安装即可（CPU 版）：
> `pip install torch --index-url https://download.pytorch.org/whl/cpu`

## 如何运行

```bash
# 启动 marimo 编辑器（会自动打开浏览器）
marimo edit notebooks/

# 或者只打开某一课
marimo edit notebooks/01_为什么需要NumPy.py
```

第一次使用请先打开 `notebooks/00_课程路线图.py`，里面有 marimo 的五分钟上手指南和完整课程地图。

## 关于课程数据文件（data/ 目录）

- 如果你所在网络下载失败，请看该课里给出的手动下载说明

**预训练语言模型权重**（第 37 课）：`data/charlm37.npz`（约 1.7 MB，随课程一起分发），
存放 RNN 与 LSTM 字符级语言模型的早停点参数和完整训练记录——交互生成实验直接加载它，
秒出结果；训练循环的完整代码在课内现场演示。

## 学习建议

1. **不要只看**：每课的代码单元都亲手运行、亲手修改参数
2. **卡住是正常的**：看报错的最后一行、把数组改小到 3×3 打印出来看、回头重读讲义——这三招能解决 90% 的问题
3. **稳扎稳打**：每课的练习做完再进入下一课；本课程的后续内容都建立在前面的地基上
